# Анализ оттока клиентов телеком-компании (Telco Churn)

Ретроспективный A/B-анализ влияния семейного статуса на отток клиентов, средний чек и пожизненную ценность (LTV). Проект демонстрирует навыки работы с SQL (оконные функции, CTE) и Python (Pandas, DuckDB) для извлечения бизнес-инсайтов.

## Инструменты
- **Языки:** Python, SQL
- **Библиотеки:** Pandas, DuckDB, Matplotlib, Seaborn
- **Методы:** Ретроспективный A/B-тест, когортный анализ, расчет продуктовых метрик (Churn Rate, LTV, Retention)

## Ключевые инсайты
На основе анализа ~7 000 клиентов были выявлены следующие закономерности:
1. **Семейные клиенты лояльнее:** у клиентов с партнером (Partner='Yes') уровень оттока (Churn Rate) ниже на **13.3 п.п.** (19.6% против 32.9%), а средний стаж жизни в компании почти в 2 раза выше (42 мес. против 23.4 мес.).
2. **Высокий LTV:** пожизненная ценность (LTV) клиентов с партнером почти в 2 раза выше благодаря сочетанию более высокого среднего чека и долгого срока удержания.
3. **"Ловушка дорогого онбординга":** контринтуитивный факт - ушедшие клиенты в среднем платили на 21% больше ($74.44 vs $61.27), но имели стаж в 2 раза меньше (18 мес.). Это указывает на завышенные ожидания от дорогих тарифов на старте.

## Бизнес-рекомендации
- Внедрить триггерные коммуникации для новых клиентов с высоким чеком в первые 90 дней.
- Разработать и продвигать "семейные" тарифные бандлы для увеличения стоимости переключения (switching cost).
- Пересмотреть процесс онбординга для премиум-сегмента, чтобы быстрее демонстрировать ценность продукта.
